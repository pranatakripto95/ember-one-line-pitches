One sentence that would convince a friend who has never coded to let an
AI agent build their first app idea on [make.fun](https://make.fun).

## The pitch

> Tell make.fun your app idea in plain words and let an AI agent build it
> for you — you only pay the entry that wins, so the only thing you risk
> is finally seeing your idea come alive.

## How it works

`main.ts` writes that single sentence (182 characters, one line)
to `/output/entry.txt`. No network, no secrets, no dependencies — just
Node.

```sh
node main.ts
```
